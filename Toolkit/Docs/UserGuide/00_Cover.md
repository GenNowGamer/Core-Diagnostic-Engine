# Core Diagnostic Engine

## User Guide

Diagnosing and Repairing Windows PCs

This guide explains how to use the Core Diagnostic Engine (CDE) toolkit from a bootable USB drive or from Windows. It is written for technicians and anyone helping fix a computer, even if you are not an advanced Windows expert.

> **Important:** Always back up important data before running repairs. Some tools change system files, the boot configuration, or security settings.
